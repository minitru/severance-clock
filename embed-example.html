This is somebody's web page

An example of the sign embedded in ordinary content. The numbers below are made up.

A paragraph of the page's own writing sits above the sign. The sign is one <iframe> tag pasted into the page; it takes the full width of the column and keeps its two-to-one shape on a phone or a desktop.

And the page carries on underneath. Nothing else is needed: no script on the host page, no account.

The tag comes from the Copy embed code button on the clock, and looks like this:

<iframe src="https://minitru.github.io/severance-clock/#v=…&embed=1"
        title="Dan's Increased Severance Clock"
        style="width:100%;aspect-ratio:2/1;border:0" loading="lazy"></iframe>

It shows the sign as it was when the code was copied. After a new win, copy the code again and replace the tag.
